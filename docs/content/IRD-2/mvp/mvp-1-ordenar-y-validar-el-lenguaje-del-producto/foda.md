| Fortalezas                                                                                                                                                                                                                                                                                                        | Debilidades                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| - La empresa publica especialización en telas decorativas, revestimientos y accesorios (`evidencia`).<br>- Existen canales y puntos de contacto públicos para showroom, catálogo y muestras (`evidencia`).<br>- El MVP puede trabajar sobre una muestra sin depender de una plataforma tecnológica (`hipótesis`). | - La consistencia entre fichas, referencias originales y unidades de venta no está demostrada (`pendiente_campo`) → R1.<br>- La autoridad para aprobar normalizaciones y mantenerlas vigentes no está definida (`pendiente_campo`) → R3.<br>- La relación entre SKU, ubicación y estado de disponibilidad puede estar fragmentada (`pendiente_campo`) → R2. |

| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## TOWS

|                     | Oportunidades (O)                                                                                                                                                                    | Amenazas (A)                                                                                                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Fortalezas (F)**  | **FO:** usar la experiencia pública en productos decorativos y los puntos de atención existentes para seleccionar 2–3 familias y construir una taxonomía validable en showroom → R1. | **FA:** conservar la referencia original del proveedor y exigir una regla documentada antes de crear el SKU interno, para reducir ambigüedad entre marcas → R1.  |
| **Debilidades (D)** | **DO:** asignar un responsable por atributo y un estado de validación en la ficha piloto para convertir una brecha de ownership en una regla observable → R3.                        | **DA:** bloquear la propuesta de integración hasta comprobar que la variante, unidad y estado pueden reconciliarse en una muestra física o documental → R2 y R4. |

## Implicación para esta semana

La estrategia prioritaria es FO/FA: seleccionar una muestra de familias conocidas, conservar el origen de cada atributo y falsar primero la consistencia de ficha y unidad antes de diseñar integración.
